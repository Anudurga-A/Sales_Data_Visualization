# Sales Data Visualization 📊

## 📌 Project Overview
This project focuses on visualizing sales data using Python.
Bar charts and line charts are created to compare monthly sales
and identify sales patterns and trends.

## 🎯 Objective
To understand how data visualization helps analyze numerical
data and identify sales trends effectively.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📂 Dataset
The dataset contains monthly sales information from January to June.

| Month | Sales |
|---|---:|
| January | 12000 |
| February | 15000 |
| March | 10000 |
| April | 18000 |
| May | 22000 |
| June | 25000 |

## 📈 Visualizations
1. **Bar Chart:** Compares sales across different months.
2. **Line Chart:** Shows monthly sales trends.

## 🔍 Key Observations
- June recorded the highest sales of 25,000.
- March recorded the lowest sales of 10,000.
- Overall, sales showed an increasing trend from January to June.

## ▶️ How to Run
1. Open Jupyter Notebook.
2. Open `Sales_Data_Visualization.ipynb`.
3. Run all cells in order.
4. View the bar chart, line chart, and observations.

## ✅ Conclusion
This project demonstrates how Python visualization libraries
can help compare sales data and identify meaningful trends.
